# ---------------------------------------------------------------------------
# MODULE VALIDATION SCOPE
# ---------------------------------------------------------------------------

NOTE: FIPS 140-3 validates cryptographic modules. It does not validate repositories, applications, systems, or codebases.
NOTE: A CMVP certificate is issued to a specific cryptographic module, not to a product or codebase that uses it.
NOTE: Vault Community internal cryptographic operations are not performed in a CMVP-validated module.
